# Building
Saffron is _Linux-Only_ for the time

## Dependencies
GLFW is ==not included== but ==required== in Saffron so install it like this:
### Ubuntu-Based Systems
#### `apt install libglfw-dev`

## Compilation
just execute the run script 
#### `./run`
